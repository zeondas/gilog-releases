# 기록(gilog) 설치 파일

파주시 도로관리과 업무 기록 앱 "기록"의 **설치 파일만** 올리는 곳이에요. 코드는 여기 없어요.

- 설치 파일은 오른쪽 [Releases](https://github.com/zeondas/gilog-releases/releases)에서 받아요.
- 같이 올라가는 파일
  - `giLog_<버전>_x64-setup.exe` – 설치 파일
  - `giLog_<버전>_x64-setup.exe.sha256` – 설치 파일 지문(SHA-256). 받은 파일이 같은지 견줄 때 써요.
  - `giLog_<버전>_x64-setup.exe.sig`·`latest.json` – 앱의 자동 업데이트가 읽어요.
- 이용 약관은 설치할 때 보여요(설정 › 정보 › 이용 약관에서도 볼 수 있어요).
